# Termgram Wiki

[English](en/Home.md) · [简体中文](zh-CN/Home.md)

Termgram is a keyboard-first Telegram client for direct messages and groups.
Choose a language for setup, keybindings, Lua configuration, daily workflows,
and maintenance documentation.

Termgram 是面向私聊与群组的终端 Telegram 客户端。请选择语言，查看安装、快捷键、
Lua 配置、日常操作与维护说明。

Documentation follows its source revision. Open PR features may not be available
in the latest release. 文档对应其来源版本，尚未合并的 PR 功能不一定已包含在最新发行版中。
