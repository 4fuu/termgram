# 附件与文件预览

[English](../en/Attachments.md) · [指南首页](Home.md)

## 准备发送文件

在打开的聊天中输入 `:attach /绝对路径`。多文件使用当前平台的参数引号规则，
也支持本机 `file:` URL。路径直接复用 Yazi 的解析器，不执行 shell、不展开变量。
默认情况下，会话中的终端粘贴会进入输入框作为文字，文件路径也如此。

文件在后台加入发起操作的聊天草稿，此时不会上传。输入框显示附件数量。
用 `:attachments` 或在输入框按 Ctrl-O 查看文件名、大小和发送格式，点击行或用 j/k 选择。

| 附件列表中的按键 | 行为 |
| --- | --- |
| a | 打开 `:attach`，继续添加 |
| p | 支持的图片在 Telegram 照片与原始文件之间切换 |
| d / Delete | 移除所选引用；准备期间则取消准备 |
| o / Enter | 预览支持的图片，Esc 返回列表 |
| O | 在系统文件管理器中定位原件 |
| i | 回到说明文字输入框 |
| Esc | 返回之前的视图，保留草稿 |

在**输入框内**按 Enter 才会发送，第一份文件携带输入框中的说明文字和回复对象。
每个草稿最多八份文件、共 2 GiB。上传与下载共享最多 32 个任务的队列，同时执行三个。
当前版本逐条发送文件，相册组合会在后续版本加入。

文件引用、格式选择和内容摘要随[本地草稿](UX.md)保存，正常重启后恢复。
移除附件不会删除原文件。上传前会一边生成私有临时副本，一边检查内容摘要；
原文件缺失或发生变化时，会在上传前报错。更改过的文件需要重新添加、重新检查。
传输结束或取消后自动删除上传副本。在准备期间切换聊天，结果仍加入最初的聊天草稿。

如需把识别到的粘贴路径自动加入草稿，在 Lua 中启用：

```lua
attachments = { auto_attach_paths = true },
```

此选项也不会自动发送；无法识别的内容仍作为文字。列表使用 `attachments` 按键上下文，
动作包括 `attach`、`attachments`、`remove_attachment`、`attachment_format`、`preview`、`reveal`。

## 收到的文件

用 `j/k` 选择附件消息，或点击它，再按大写 `O`（`Shift-O`），即可在系统文件管理器
中显示文件。这里是单次按键，不依赖长按计时；终端上报的重复按键事件会被忽略。
同一附件下载期间重复操作不会启动额外下载。

已有原尺寸图片预览或下载文件时直接复用，否则先下载原始附件，再自动显示。
动态贴纸的缩略图只用于预览，`O` 下载其原始文件。缓存文件已被删除时会重新下载。
失败原因显示在状态区，可再次操作重试。

macOS 在 Finder 中选中文件，Windows 在资源管理器中选中文件；Linux 用 `xdg-open`
打开所在目录，能否选中文件取决于文件管理器。不会执行附件本身。即使设置中
Enter 下载行为选择 **Keep in cache**，`O` 仍表示明确的“显示文件”操作。

单击媒体只选择并显示可用按键。`o` 在终端展开图片或贴纸，Esc 关闭大图，`i` 回复，
`O` 定位原始文件。选择不会直接激活链接、机器人按钮或文件管理器操作。
`g n` / `g p` 切换可操作项，Enter 激活。Lua 动作为 `preview`、`next_action`、
`previous_action` 和 `reveal`；大图使用 `preview` 上下文。

使用 Telegram 媒体 ID 和请求编号校验结果，避免旧下载覆盖已编辑或已删除的附件。
文件映射随消息缓存保存，重启后可复用。完成的文件位于
`<会话文件名>.media/<Telegram 账号 ID>/`。每个目录最多保留 512 个已完成文件，
目标体积上限为 1 GiB，超过后清理较旧文件。刚下载的文件即使单独超过体积上限也会
保留，之后的清理仍可能移除它。需要长期保存的文件应复制到缓存目录之外。

下载中的文件复用维护中的 `tempfile` 库，与已完成文件分开。取消下载会清理临时
文件，进程中断遗留的文件会在下一次开始传输前清理。同一账号缓存只允许一个进程
持有，未结束的媒体任务会保留锁直到清理完成，避免两个客户端同时推进同一缓存的
同步进度。

照片、图片文档和贴纸在消息流内预览，只请求可见预览，应用最多同时等待两个预览下载，
全部网络传输共享有界工作任务。动态 TGS/WebM 贴纸显示 Telegram 的栅格缩略图并标注为
静态预览；失败预览选中后可按 `o` 或 Enter 重试。Ctrl-L 重绘，协议说明见[终端](Terminal.md)。
本地文件使用 `:attach` 加入草稿，检查后再发送。
