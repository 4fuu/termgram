# 聊天发现与资料

[English](../en/Chats.md) · [使用指南](Home.md)

## 打开聊天

用 `:chat` 和 Tab 按名称、配置别名或 ID 选择缓存聊天。
用 `:open @alice_name` 在 Telegram 上查找用户名，再按 `i` 输入。
`:open https://t.me/example/123` 也可以定位消息链接。
已有草稿、未读数及文件夹状态会保留。

只有按 Enter 后才请求 Telegram，输入过程中不联网查询；请求有超时。
开始输入或打开其他聊天会取消等待中的导航，过期结果不会改变当前视图。
缓存聊天可以离线打开。本版本仍不支持广播频道。

## 预览和加入邀请

`:join https://t.me/+hash` 先预览群邀请，也支持 `t.me/joinchat/hash` 和
`tg://join?invite=hash`。用 `:open` 或激活消息中的邀请链接，也会进入同一个预览。
预览显示群名、可用简介、人数和 Telegram 的诈骗/冒充标记。

默认选择取消：按 Down 选择加入或申请加入，再按 Enter 确认；
鼠标点击只选中选项，由 Enter 确认。已经加入的群提供“Open chat”。
提交前会重新检查邀请。

需要管理员批准时显示申请已提交。提交中关闭面板不会取消服务端请求，
结果通过状态提示报告，也不会改变当前聊天。超时或失败后应重新打开邀请，
检查当前成员身份再重试。过期或撤销的邀请显示 Telegram 错误；订阅付费、广播频道、
机器人验证需要官方客户端。请求日志不包含邀请 token，偏好设置和磁盘命令历史不保存邀请。

## 查看资料和发送限制

`:info` 打开选中聊天的资料：完整名称、用户名、简介、可用人数、当前身份、通知静音、
文字/照片/文件权限和慢速模式。j/k 或鼠标滚轮滚动，Ctrl-R 刷新，Esc 关闭。
长名称和简介会换行。

当前可见聊天最多每分钟后台刷新一次，同时只有一个资料请求；权限更新会废弃旧结果。
离线查看显示资料获取时间。已知发送限制会显示在输入框 ghost text 和底栏。
受限时尝试发送会保留正文、回复和附件草稿。慢速模式显示等待倒计时，
每次允许一个待发送消息或附件。

服务端拒绝会显示可读的权限或等待原因，并保留重试内容；最终发送权限由 Telegram 检查。
此页面不修改身份、不封禁用户、不支付消息费用。[通知静音](Notifications.md)和禁止发言
是不同的状态。命令补全见[冒号命令](Commands.md)，导航方式见[快捷键](Keybindings.md)。
