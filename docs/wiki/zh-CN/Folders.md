# Telegram 文件夹

[English](../en/Folders.md) · [指南首页](Home.md)

Termgram 读取 Telegram 中已配置的文件夹，包括共享文件夹。文件夹顺序、置顶聊天、
包含与排除规则会同步，并按账号缓存。使用 Telegram Desktop 等官方客户端创建或
编辑文件夹后，Termgram 会自动更新。

在聊天列表中用 `[`、`]` 切换上一个、下一个文件夹，边框显示名称与位置。对应的
Lua 动作为 `chats` 上下文中的 `folder_previous` 和 `folder_next`。`/` 只过滤当前
文件夹。切换文件夹保留已打开的聊天、阅读位置和草稿。`jump alias` 会从“全部聊天”
打开目标，因此目标不在当前文件夹时也能跳转。参阅[配置](Configuration.md)。

显式排除优先，其次是显式包含与置顶，最后才是动态规则。支持联系人、非联系人、
机器人、群组，以及未读、静音、归档筛选。机器人属于独立类别。按照 Telegram
Desktop 的规则，静音但有未读提及的聊天仍可进入文件夹，除非已归档；没有独立静音
设置的聊天继承账号的通知默认设置。其他客户端产生的已读通知会更新“未读”文件夹。
需要重试时可按 `Ctrl-R` 刷新文件夹和聊天列表。

Termgram 目前提供私聊和群聊，暂不展示广播频道，包括文件夹中的广播频道。“全部
聊天”包含已缓存的归档会话；是否排除归档由各文件夹的规则决定。本地外观设置不会
修改 Telegram 的共享文件夹数据。

实现参考：[Telegram 文件夹协议](https://core.telegram.org/api/folders)。
