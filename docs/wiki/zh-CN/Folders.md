# Telegram 文件夹

[English](../en/Folders.md) · [指南首页](Home.md)

Termgram 读取 Telegram 中已配置的文件夹，包括共享文件夹。文件夹顺序、置顶聊天、
包含与排除规则会同步，并按账号缓存。使用 Telegram Desktop 等官方客户端创建或
编辑文件夹后，Termgram 会自动更新。

在聊天列表中用 `[`、`]` 切换上一个、下一个文件夹，边框显示名称与位置。对应的
Lua 动作为 `chats` 上下文中的 `folder_previous` 和 `folder_next`。`/` 只过滤当前
文件夹。切换文件夹保留已打开的聊天、阅读位置和草稿。`jump alias` 会从“全部聊天”或“归档”
打开目标，因此目标不在当前文件夹时也能跳转。参阅[配置](Configuration.md)。

显式排除优先，其次是显式包含与置顶，最后才是动态规则。支持联系人、非联系人、
机器人、群组，以及未读、静音、归档筛选。机器人属于独立类别。按照 Telegram
Desktop 的规则，静音但有未读提及的聊天仍可进入文件夹，除非已归档；没有独立静音
设置的聊天继承账号的通知默认设置。其他客户端产生的已读通知会更新“未读”文件夹。
需要重试时可按 `Ctrl-R` 刷新文件夹和聊天列表。

Termgram 目前提供私聊和群聊，暂不展示广播频道，包括文件夹中的广播频道。

## 归档

Archive（ID `1`）是独立文件夹；All chats（ID `0`）不展示归档聊天。
选中聊天后按 `e`（`archive`）归档，在 Archive 中按相同按键取消归档。
自定义文件夹仍遵循自己的包含规则与 `exclude_archived` 规则；其他客户端的变更会自动同步。

## 置顶聊天

在聊天列表按 `p`（`pin`）置顶或取消置顶，`Ctrl-K` / `Ctrl-J`（`pin_up` / `pin_down`）
上移或下移置顶聊天。主列表、Archive 和每个自定义文件夹分别使用独立的服务端顺序。
`^` 标记表示置顶，其他聊天的新消息不会挤到置顶聊天前面。排序后仍选中同一聊天，
置顶顺序会缓存，重启后立即可见。

与 Telegram Desktop 一样，在自定义文件夹内取消置顶后，聊天仍保留为显式包含项。
修改置顶会保留服务端的标题、颜色、共享文件夹属性与筛选规则。置顶与归档操作需要
联网，等待服务端确认后更新；服务端数量限制或权限错误会明确显示。本地外观设置
不会修改 Telegram 的共享文件夹数据。

实现参考：[Telegram 文件夹协议](https://core.telegram.org/api/folders)。
