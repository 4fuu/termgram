# 投票与测验

[English](../en/Polls.md) · [指南](Home.md)

投票题目和选项直接显示在消息中。选中投票后按 `v` 或运行 `:poll` 打开投票面板；
当前消息动作是投票时，Enter 也可以打开。面板会先刷新消息，离线时仍可阅读缓存。

| 投票面板内 | 操作 |
| --- | --- |
| j/k 或 Down/Up | 移动到其他选项 |
| 点击选项、Space 或 Enter | 在本地勾选或取消选项 |
| Ctrl-S | 提交所选答案 |
| u，再按 Ctrl-S | Telegram 允许时撤回已有投票 |
| Ctrl-R | 刷新，并恢复服务器记录的本人选择 |
| PageUp/PageDown、Home/End、鼠标滚轮 | 滚动长题目、选项或错误提示 |
| s | 展开或隐藏剧透 |
| Esc 或 q | 关闭面板 |

勾选不会立即投票。单选题只保留一个选项，多选题可以勾选多个。
清空选择后按 Ctrl-S 才会撤回已有投票。测验及禁止重新投票的题目不允许修改答案。
关闭面板会丢弃尚未提交的选择；已经提交的请求继续在后台执行。
请求失败或无法确定结果时，需要先刷新再重试；刷新会用服务器确认的选择替换本地选择。

提交前，面板会说明这是公开投票还是匿名投票。成员资格、地区限制及其他投票条件由
Telegram 验证。题目选项变化会使当前选择失效。发送前还会重新检查最新消息，
使用 Telegram 原始的选项 ID 提交，避免选项重排后投到另一个答案。

投票后或题目关闭后显示票数及百分比，并遵守“关闭前隐藏结果”的设置。
测验解析在结果可用时显示。剧透默认隐藏；第一次选择隐藏的投票会先显示内容，不勾选答案。
投票状态也显示在底栏的 `message` 组件中，操作提示使用实际生效的 Lua 快捷键。

实时更新会同步同一投票的缓存副本。可见投票还会在后台定期刷新，通常间隔 30 秒，
最多两个请求同时进行。离开视图或终端失去焦点后不再发起新刷新；确认已关闭的投票
停止定期刷新。离线缓存中的票数可能较旧；打开投票面板时始终请求最新信息。

本版本支持阅读普通投票和测验、投票及撤回。尚未支持创建投票、查看投票者列表、
为开放选项题目添加答案，以及题目或答案中的媒体。媒体投票会明确显示只读提示，
需要在官方客户端查看并投票。

可以在 `conversation` 中用 `run = "poll"` 改绑入口。`poll` 上下文支持
`up`、`down`、`toggle_poll_answer`、`send`、`retract_vote`、`refresh`、`spoilers`、
`page_up`、`page_down`、`home`、`end` 和 `cancel`。
