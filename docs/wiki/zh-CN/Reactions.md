# 消息回应

[English](../en/Reactions.md) · [指南](Home.md)

回应以紧凑的一行显示在消息下方，包含 emoji 和数量。本人选择有 `●` 标记并使用
强调色。底栏显示回应总数，以及当前动作的快捷键。

选中已送达的消息后按 `g e`，或运行 `:react`。已有回应行也可以用鼠标选中，
再按 Enter 打开选择器。选择器会读取 Telegram 在当前聊天中允许的 emoji。

| 回应选择器内 | 操作 |
| --- | --- |
| j/k 或 Down/Up | 选择回应 |
| PageUp/PageDown、Home/End | 翻页或跳到首尾 |
| 鼠标点击 / 滚轮 | 选中一行 / 移动选择 |
| Enter 或 Space | 添加选中的 emoji；已由本人添加则移除 |
| u | 移除此消息上本人的全部普通及自定义 emoji 回应 |
| Ctrl-R | 刷新数量、本人选择和聊天权限 |
| Esc 或 q | 关闭 |

点击只选择，Enter 和 Space 才提交。一次只允许一个修改请求。
关闭面板后，已经提交的请求继续执行，失败仍会显示在底栏。
出错或无法确定结果时，先刷新再重试。按住按键产生的重复事件不会反复提交。

每次修改都会重新读取确切消息、可用回应和 Telegram 的数量限制，并保留其他选择的顺序。
添加后超过个人上限时，会按官方行为替换最早的选择。
如果本人选择已在其他客户端改变，会提示刷新，避免覆盖该变化。
不可用 emoji、聊天的不同回应种类上限都会检查，最终权限以 Telegram 为准。

回应数量会缓存，离线也能阅读。实时更新同步到对话、搜索结果、置顶和回复预览，
不包含本人选择的部分更新不会清掉已知选择。有回应的可见接收消息还会批量定期刷新，
视图不变时最多每 30 秒一次，同时最多一个批量请求；隐藏或失去焦点时不发起新请求。

本版本支持添加和移除普通 emoji。已有自定义 emoji 的数量以文本回退显示，
修改其他回应时保留其身份。尚未提供自定义 emoji 选择、动画、回应者列表、
付费回应或 Saved Messages 标签编辑。可以阅读星星计数，不发送支付请求；
Saved Messages 标签会显示只读原因。

入口动作是 `conversation` 中的 `reactions`；选择器使用 `reactions` 上下文，
支持 `open`、`clear_reactions`、`refresh`、`up`、`down`、`page_up`、`page_down`、
`home`、`end` 和 `cancel`。
